# Gumdrop

[![License][license-badge]][license-link]
[![Version][version-badge]][version-link]
[![Build][build-badge]][build-link]

Frontmatter-driven templating, data resolution and Markdown rendering. Write a Markdown document
whose YAML frontmatter references other documents and data files, and Gumdrop resolves those
references, renders the template, and produces HTML — from the command line, in the browser, or as
a library.

## Setup

Install via `npm`:

```bash
npm install gumdrop
```

## Usage
